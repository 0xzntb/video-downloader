# Code of conduct

Viddl is a small project with a small surface: an issue tracker, pull requests,
and a program people run on their own machines. Everyone is welcome to take part
— reporting a bug, translating a sentence, sending a patch, or asking why
something works the way it does.

## What is expected

- **Be decent.** Disagree with the idea, not the person. Say what is wrong with a
  change, and how you would know it was right.
- **Assume a reason.** Most odd code and most odd decisions in a project this size
  are a trade-off someone made on purpose, and the comments usually say which.
  Ask before concluding it was carelessness.
- **Be patient with language and with questions.** This project's prose is
  British English, its documentation is translated into Spanish, and its users
  include people who have never used a terminal. A question that seems obvious to
  you is the reason the README has a *When something goes wrong* section.
- **Respect privacy.** A link, a log line or a screenshot someone posts is about
  them. Do not copy it elsewhere, and do not ask for a signed link, a cookie or a
  password: `SECURITY.md` says what is useful instead, and it is never those.
- **No harassment.** In particular, nothing that demeans someone for their
  identity, experience, language, or the machine they happen to have.

## What is not acceptable

Insults, personal or political attacks, sexual attention or imagery, deliberate
intimidation, sustained disruption of a discussion, publishing someone's private
information, and dismissing a report because the person making it is new here.
This applies in issues, pull requests, commit messages, code comments and
anywhere else the project is the context.

## If something happens

Report it privately through the repository's **Security → Report a
vulnerability** page, the same private channel `SECURITY.md` uses, and say that
it is a conduct report rather than a vulnerability. Reports are read by the
maintainer and not discussed in public before the person who reported it has been
told what happened.

What follows depends on what happened and whether it is a pattern: a private
word, an edited or deleted comment, a request to step away from a thread for a
while, or — for harassment or a repeated pattern — a permanent ban from the
project's spaces. The person reporting is told the outcome; the person reported
is told enough to answer for it.

## Scope

This applies to the project's own spaces (issues, pull requests, reviews,
discussions) and to anyone representing the project elsewhere. It does not
govern what people do on their own accounts, in their own projects, or with the
program — Viddl is a local tool, and what someone downloads with it is theirs.

## Credit

The shape of this document, and much of its wording, follows the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1,
which is the standard other projects use. It is kept short on purpose: a code of
conduct nobody reads protects nobody, and the expectations above are the ones
this project actually enforces.
